# Пыжпец Jump — Skybound Edition 6.0

Android Studio / Kotlin Canvas. Откройте папку проекта в Android Studio, дождитесь Gradle Sync и нажмите Run.
Полная сборка APK в среде, где делалась правка, не выполнялась (нет Android SDK): код проверен компилятором Kotlin
на заглушках Android API, вёрстка экранов — предпросмотром. Обязательно проверьте Build/Logcat у себя.

## Что изменилось в 6.0
1. **Пингвин** — новый нарисованный персонаж (оригинальный: пингвин в бирюзовой шапке с помпоном), три позы:
   взлёт, падение, приземление (сплющивается), зеркалится по направлению движения, слегка наклоняется на повороте.
   Спрайты: `app/src/main/assets/art/penguin_*.png`. Переключатель — `NEW_PENGUIN` в начале `MainActivity.kt`
   (`false` вернёт прежнего пингвина из фигур; в сборке `old_penguin` он уже выключен).
2. **Кнопки** главного меню — рисованные, с неровной «карандашной» обводкой, штриховкой и бликами
   (`btn_primary.png`, `btn_secondary.png`). Если картинка не загрузилась, рисуется запасной вариант.
3. **Шрифт** увеличен везде (в этом шрифте заглавные буквы низкие, ~0.42 кегля), длинные надписи сами ужимаются под ширину.
4. **Убраны A/D** — из обработки клавиш и из текста меню. Стрелки ← → остались (для эмулятора), пробел/Enter — действие, P/Esc — пауза.
5. **Платформы**: генерация по «опорной цепочке» — каждая следующая платформа гарантированно достижима
   (подъём ≤ 130 при высоте прыжка ≈ 156, горизонтальный сдвиг ограничен временем полёта), без зиг-зага.
   Поверх цепочки случайные дополнительные платформы: внизу их много (~14 на экран), выше всё меньше (~8 на 20 000, дальше только цепочка).
   Исчезающие «+» никогда не входят в цепочку. Ширина, размах и скорость движущихся платформ варьируются; ширина падает с высотой.
   Проверено симуляцией бота (скорость 230 px/с): 16 из 16 забегов до высоты 40 000 без тупиков.
6. **Горы**: больше не растворяются. Два слоя нарисованных гор стоят на земле и уезжают вниз за экран с параллаксом;
   облака рисуются поверх гор (нарисованные облака, 3 вида).
7. **Интерфейс** целиком в рисованном стиле: бумажная текстура с каракулями, плашка счёта, баннер зон, кнопка паузы,
   панели паузы/конца игры/настроек/рекордов, ползунки. Тексты переведены на русский.

## Исходники рисунков
`art_source/` — генератор спрайтов (Chromium Canvas): `npm i playwright && node gen.js` кладёт PNG в `out/`.
